## Implementation

1. Add pure EDF planning in backend/app/evc/scheduler_edf.py and shared immutable scheduling input/output types and metrics in EVC-owned modules. The transactional entry accepts an explicit run UUID, finite start/end dates and optional region; it calls AuthzPort first and runs all mandatory work inside one unit_of_work. A reused run UUID yields coded Conflict. IDs derive deterministically from run/request IDs.
2. Sort requests by (due_by, requested_at, request_id), then consider slots by (date, configured AM/PM order, slot_id). For each request, choose the first slot with residual capacity and a complete panel returned by select_panel. Reserve its capacity and experts in the pure working state before considering the next request; add assignment facts for selector workload/rotation. Existing proposed and published assignments are reservations. Leave unschedulable requests QUEUED with a controlled reason; do not relax constraints or create partial panels.
3. Separate soft due_by from the finite planning horizon. Extend EVC-local eligibility/snapshot inputs with an optional explicit planning-until date; default remains the current due_by behavior for existing selector previews. EDF can evaluate dates after due_by when pinned DEMO scheduler policy permits it; original persisted due_by, request pin and P2 clocks never change. Load availability/reservations through the horizon so late placement is real, not an empty-facts artifact. No scheduling before earliest_date, the logical request date, the run's start or logical clock's date.
4. Add a labelled expert_pool.scheduler policy in P1 routes.yaml: capacity_unit PANELS, allow_late true, source_status DEMO_ASSUMPTION, assumption_code EDF_PLANNING_UNCONFIRMED. Capacity means one request/panel per assignment record, not one expert seat. Use existing actual slot rows only. Keep r1 checksum rejection and fresh disposable demo verification; no existing case is repinned.
5. Shared evaluator takes the same immutable problem and a proposed allocation list for either EDF or future CP-SAT. Report queue_count, scheduled, unscheduled, late_count, total_lateness, max_lateness, total_waiting, hard_constraint_violations and an ordered lateness_days vector (null for unscheduled). Lateness=max(0, placement_date-original_due_by); waiting=placement_date-logical requested_at date. Validate queue membership, one placement per request, horizon/earliest bounds, capacity, panel size/uniqueness, active status, availability, COI, region, expertise minimum and expert/date/part double booking. Never persist a result with a nonzero violation count.
6. Define comparison inputs and request order once. Compare scheduling cardinality before lateness/waiting; dropping requests must not masquerade as improvement. Pure EDF/CP-SAT evaluations must use the same queue, slots, policy, prior reservations and clock snapshot. Do not benchmark CP-SAT on a fresh DB snapshot after EDF proposals have consumed capacity. Compute an input fingerprint and retain its bytes as numeric run parameters for identity checks; do not store strings in numeric_json columns.
7. Transactional persistence: acquire an EVC scheduling advisory lock, deterministically lock queued request/slot/expert rows, then refresh facts. This serializes proposals and cooperates with existing expert availability/COI row locking and slot/assignment FK locks. Future publication must use the same capacity/reservation discipline; do not claim the published-only DB unique index protects proposals. Resolve case scope through CasePort/AuthzPort; no cross-module internal imports or foreign-schema SQL.
8. Persist one schedule_run (EDF, PROPOSED), one unpublished assignment per scheduled request (coded DEMO_PANEL role), and set those requests PROPOSED. Unscheduled requests remain QUEUED. Persist numeric/boolean/null parameters and metrics only. Append a run event and an application-aggregate assignment/request-state event inside the same transaction. Any clock/guard/insert/ledger failure rolls back all effects. This does not publish, complete EVC, close clocks or trigger P2 overdue work.
