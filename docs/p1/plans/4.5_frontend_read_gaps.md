## Implementation

1. **Runs.** Migration evc_0004 adds `schedule_run.region_scope` (upper-cased, NULL = every region) and `evc.schedule_run_request` (run, request, ordinal, outcome PROPOSED/UNSCHEDULED, explanation code). `scheduler_edf.handle` writes both inside the propose transaction and sets `outcomes_recorded` in the numeric run parameters. `app/evc/reads.py` serves `GET /api/evc/schedule/runs` (filters status, algorithm, region; offset/limit; newest first) and `GET /api/evc/schedule/runs/{run_id}` (summary plus solver facts, held assignments with `published`, unscheduled requests with `explanation_code`, and the requests a discard withdrew). Read with `evc.expert.read`; regional officers only see runs planned for their region (READ-001). Propose now reports the effective `region_scope` (an RO's own region when the body named none).
2. **Per-case EVC.** `GET /api/applications/{id}/evc` returns the case's requests newest first (`current` is the newest) with the published visit only: date, AM/PM, panel role and expert references (READ-003). Scoped like the case through CasePort/`application.read`. The queue takes an `application_id` filter.
3. **document_ref.** `app/intake/documents.py` checks every provided reference before an item is written: a version of the same application with status AVAILABLE and scan clean, else 422 DOCUMENT_REF_NOT_AVAILABLE or DOCUMENT_REF_UNKNOWN. UUID5 fixture references that name no version pass only in DEMO_MODE (DOC-REF-001); the seeds keep working unchanged and no P2 code changes.
4. **Application read.** `GET /api/applications/{id}` passes the case region to the policy and refuses another region, like `/cases/{id}` (READ-004).
5. **Deficiency vocabulary.** `GET /api/rulesets/{key}/deficiency-vocabulary` returns the pinned item kinds, reason codes, response rule and DEMO labels (`ruleset.read`), 404 when the ruleset is not loaded or has no deficiency config.
6. **Committees.** `GET /api/cases/{id}/committees`: id, formation ordinal, type, status, member references with roles, task and report counts, latest report version (number, author, hash). Uses the case's scope (READ-006).
7. **Seed.** `seed_evc_demo` adds six DEMO experts with availability in each seeded institution region (EVC-SEED-002).

All new endpoints are GETs; no new POST, so no new idempotency surface. No policy, event, port or shared-type change.

## Limits

Runs made before evc_0004 cannot be scoped to a region or explained; they say so instead of guessing. Collection scope still resolves cases one by one through CasePort (CA-006). The document check covers checklist items only; deficiency response references are unchanged. DEMO_MODE fixture references remain unverifiable by design and are labelled as such.
