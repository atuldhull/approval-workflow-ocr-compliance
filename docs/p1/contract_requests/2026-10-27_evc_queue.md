## Exact proposed port addition

Reuse existing CaseRef, Anchor, UUID, Session and UnitOfWork. No contracts/types.py or enums.py edit.

```diff
--- a/contracts/ports.py
+++ b/contracts/ports.py
@@
+@runtime_checkable
+class EvcPort(Protocol):
+    def enter(self, uow: UnitOfWork, case: CaseRef, *, category: str,
+              ruleset_key: str, stage_visit_id: UUID, rule_id: str,
+              action: str, anchor: Anchor) -> UUID: ...
+    def complete(self, uow: UnitOfWork, case: CaseRef, *, ruleset_key: str,
+                 rule_id: str, action: str) -> UUID: ...
+    def cancel(self, uow: UnitOfWork, case: CaseRef, *, ruleset_key: str,
+               rule_id: str, action: str, reason_code: str) -> UUID: ...
+    def status(self, session: Session, application_id: UUID) -> str | None: ...
```

Mutators return the affected request UUID and never commit. action is the authorized canonical workflow action, not an EVC permission bypass. The EVC implementation rechecks case scope and case.<action> before mutation. status returns the latest request status (QUEUED/PROPOSED/PUBLISHED/DONE/CANCELLED) or None for workflow guards; no private ORM model crosses the port. All reads/writes are deterministic and stage-visit idempotency is enforced in the EVC database.
